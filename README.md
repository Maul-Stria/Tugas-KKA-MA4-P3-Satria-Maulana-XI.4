# Hierarki Kelas: Bangun Datar

## Deskripsi
Program ini menerapkan pewarisan dan polimorfisme
(method overriding) untuk menghitung luas bangun datar.

## Hierarki
```
BangunDatar (superclass)
 |-- Persegi (subclass) -> override luas()
 |-- Lingkaran (subclass) -> override luas()
 |-- Segitiga (subclass) -> override luas()
```

## Cara Menjalankan
```
python main.py
```

## Contoh Output
```
Persegi: luas = 25
Lingkaran: luas = 153.86
Segitiga: luas = 12.0
Bangun Umum: luas = 0
```
